# David.meyers Local

## How do I install these formulae?

`brew install david.meyers/local/<formula>`

Or `brew tap david.meyers/local` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "david.meyers/local"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
